# 카드뉴스 에이전트

주제를 입력하면 최근 소식을 조사하고, 사용자가 브라우저에서 소식을 고르고 질문에 답하고 기획을 승인하면, 그림과 글자를 얹은 카드뉴스 PNG·ZIP을 만들어 주는 웹앱입니다. 조사·원고·그림은 모두 **OpenAI API**로 합니다.

모두의연구소 「사용자와 함께 만드는 카드뉴스 에이전트」 실습에서 받은 [카드뉴스 워크플로 설계 키트(v5.0.0)](https://github.com/SunCreation/agent-building-practice/tree/v5.0.0/card-news-workflow-kit)의 PRD로 만들었습니다. 키트의 다른 원본 파일(ACCEPTANCE·ENGINE_GUIDE·EXAMPLE_RUN·REFERENCES·assets)은 원래 저장소에서 보세요.

## 흐름

주제 입력 → 최근 7일 조사 → 👤 소식 1~3개 고르기 → 심층 조사 → 👤 필요할 때만 질문 → 👤 스토리보드 승인(또는 변경 요청) → 그림 + 글자 배치 → 👤 검수·골라서 고치기 → 👤 최종 승인 → PNG·ZIP·출처·이미지 기록 내려받기

👤 표시는 앱이 사람의 선택을 기다리는 곳입니다. 기다리는 것은 고장이 아니라 정상입니다.

## 내 PC에서 실행하기 (Windows 기준)

필요한 것:

- Python 3.11 이상, [uv](https://docs.astral.sh/uv/)
- OpenAI API 키. 사용자 환경 변수 `OPENAI_API_KEY`에 넣어 두세요. 넣은 뒤에는 PowerShell 창을 새로 여세요.

**1. 앱 서버용 PowerShell 창을 하나 열고 이 폴더로 이동합니다.**

```powershell
cd C:\aiffel_work\card-news\card-news-workflow-kit
```

**2. 처음 한 번만 설치합니다.** 두 번째 줄은 카드를 PNG로 찍을 브라우저(Chromium)를 내려받아 시간이 조금 걸립니다.

```powershell
uv sync
uv run playwright install chromium
```

**3. 앱 서버를 켭니다.**

```powershell
uv run python -m cardnews
```

아래처럼 나오면 켜진 것입니다.

```
엔진: openai (gpt-5.4-mini) · 그림: openai · 저장 폴더: C:\aiffel_work\card-news\card-news-workflow-kit\data
브라우저에서 http://127.0.0.1:8765 를 여세요. 끄려면 이 창에서 Ctrl+C
```

**4. 브라우저에서 http://127.0.0.1:8765 를 엽니다.** 끌 때는 서버 창에서 `Ctrl + C`를 누릅니다.

코드를 고친 뒤에는 서버를 껐다가 다시 켜야 합니다. 지난 프로젝트는 첫 화면의 「프로젝트」 목록에서 다시 열 수 있습니다.

### 비용 없이 먼저 흐름만 보기

```powershell
uv run python -m cardnews --engine mock
```

실제 검색과 그림 생성 없이 모든 화면을 끝까지 눌러 볼 수 있습니다. 모의 화면에는 "모의 데이터입니다" 띠가 나오고, 후보 제목에는 `[모의]`가 붙습니다.

## 서버에 배포하기 (공개)

리눅스 VM(우분투 22.04/24.04, vCPU 2개·메모리 4GB 이상 권장)에 Docker로 올립니다. Chromium이 카드를 찍으므로 메모리가 너무 작으면 안 됩니다.

1. 클라우드에서 우분투 VM을 만들고, 방화벽(보안 그룹)에서 **80번 포트**를 엽니다.
2. VM에 SSH로 들어가 아래를 실행합니다.

```bash
curl -fsSLO https://raw.githubusercontent.com/rome777/card-news-agent/main/deploy/setup-ubuntu.sh
bash setup-ubuntu.sh
```

3. 처음에는 `.env`에 키가 없다고 멈춥니다. `nano ~/card-news-agent/.env`로 `OPENAI_API_KEY=` 뒤에 키를 넣고 `bash setup-ubuntu.sh`를 다시 실행합니다.
4. 브라우저에서 `http://<VM 공인 IP>/`를 엽니다. 코드를 고친 뒤 다시 배포할 때도 `bash setup-ubuntu.sh`를 실행하면 됩니다.

**공개 모드(`--public`)에서 달라지는 것**

- **접속 비밀번호:** 없습니다. 주소를 아는 누구나 쓸 수 있고, **모든 비용은 `.env`에 넣은 OpenAI 키의 계정으로 청구됩니다.** OpenAI 대시보드에서 월 예산 상한을 꼭 걸어 두세요.
- **하루 사용량 상한:** 새 카드뉴스는 하루 30개, 접속 주소 하나당 5개, 그림은 하루 150장까지입니다. `docker-compose.yml`의 숫자를 바꾸거나 `0`으로 끌 수 있습니다. 서버를 다시 켜면 그날 숫자를 다시 셉니다.
- **프로젝트 목록:** 다른 사람의 프로젝트는 보이지 않습니다. 각 브라우저는 자기가 만든 프로젝트만 기억합니다.
- **HTTPS:** 지금 설정은 HTTP(80번)입니다. 도메인이 있으면 앞에 Caddy·Nginx 같은 프록시를 두어 HTTPS를 붙이세요.

## 화면에서 하는 일

1. **주제 입력:** 주제(예: `프랑스 시위`, `AI 최신소식`)를 넣고 **조사 시작**을 누릅니다. 1~2분 걸립니다. 「작업 진행 내역」을 펼치면 실제 검색어와 읽은 원문이 보입니다.
2. **후보 고르기:** 조사 기준 시각과 기간을 확인하고 후보를 1~3개 고릅니다. 후보마다 '원문 확인함'인지 '검색 결과만 봄'인지 보이니, 원문 링크 하나는 직접 열어 제목과 날짜를 대조하세요. 후보가 적으면 **30일로 넓혀 다시 조사**할 수 있습니다.
3. **질문에 답하기:** 독자나 형식에 따라 결과가 크게 달라질 때만 질문이 나옵니다. 추천은 표시만 되고 미리 선택돼 있지 않습니다. 새로고침해도 질문은 남아 있습니다.
4. **스토리보드 확인:** 카드별 역할·제목·핵심 문장·본문·그림 장면·출처를 확인합니다.
   - 고칠 곳이 있으면 **변경 요청**에 적습니다. 예: "4번 카드 그림 장면의 돔 건물은 빼고 프랑스 국민의회로 바꿔 줘".
   - 괜찮으면 **스토리보드 승인 → 그림 만들기**를 누릅니다. 승인하기 전에는 그림을 만들지 않습니다.
5. **그림·글자 제작:** 카드마다 그림을 만들고, 글 상자와 그림을 위아래로 나눠 겹치지 않게 배치해 PNG를 만듭니다. 한 장에 10~20초 걸립니다.
   - **그림은 한 장씩 직접 보세요.** 그림 모델이 엉뚱한 나라의 지도·국기·건물을 그리거나, 그림에 글자를 넣거나, 확인되지 않은 합의(악수)를 그리는 일이 실제로 있었습니다.
   - 그러면 「글자 고치기」에서 **그림 장면**을 분명하게 고쳐 쓰고 「그림 다시 만들기」를 누릅니다.
6. **검수:**
   - 카드마다 그림 종류, 명암 대비, 경고(글 잘림·대비 부족·그림이 너무 작음)를 봅니다.
   - **휴대폰 크기로 넘겨 보기**에서 실제로 내보낼 PNG를 375px 너비로 넘겨 봅니다.
   - 그림이 실패한 카드는 이유가 보입니다. **실패한 카드 그림 다시 만들기**, 카드별 **그림 다시 만들기**, **코드 도형 그림으로** 중에서 고르세요.
7. **고치기:**
   - **글자 고치기:** 제목·본문·출처 줄·그림 장면·글 위치·크기·색·상자 진하기를 바꿉니다. 그림은 그대로 두고 그 카드만 다시 찍습니다.
   - **골라서 고치기:** 카드를 체크하고 요청을 적습니다. 범위는 자동 / 글만 / 그림만 중에서 고릅니다. 고르지 않은 카드는 바뀌지 않습니다.
   - 고치면 최종 승인이 풀리고, 이전 버전은 카드의 「이전 버전」에 남습니다.
8. **최종 승인:** 모든 카드가 완성되면 **최종 승인하고 내보내기**를 누릅니다.
9. **내려받기:** 전체 ZIP, 카드별 PNG, `manuscript.md`(원고), `sources.md`(출처), `image_log.json`(이미지 기록)을 받습니다.
10. **검증:** **내보낸 파일 검증하기**를 누르면 ZIP을 다시 열어 검사합니다. '확인 못 함' 4개(링크가 지금 열리는지, 문장이 원문과 맞는지 등)는 직접 확인하세요.

## 시간과 비용 (2026-10-23 실제 실행 기준)

| 단계 | 시간 | 사용량 |
|---|---|---|
| 넓은 조사 | 1~2분 | 입력 약 6만·출력 약 2만 토큰, 웹 검색 7회 안팎 |
| 심층 조사(질문이 있으면 답한 뒤 한 번 더) | 30초~1분 | 입력 약 6만·출력 약 7천 토큰 |
| 스토리보드 | 30~40초 | 입력 약 5천·출력 약 5천 토큰 |
| 그림 | 장당 10~20초 | 장당 약 $0.034 (`gpt-image-1.5` medium) |

토큰 요금은 모델(기본 `gpt-5.4-mini`)과 OpenAI 요금표에 따릅니다. 카드뉴스 한 편(카드 6장)에 대략 0.5달러 안팎으로 추정합니다. 실제 청구액은 OpenAI 사용량 화면에서 확인하세요.

## 실행 옵션

| 옵션 | 뜻 |
|---|---|
| `--engine mock` | 모의 엔진(비용 없음). 기본은 `openai` |
| `--openai-model`, `--openai-effort` | 조사·원고 모델과 reasoning effort. 기본 `gpt-5.4-mini`, `medium` |
| `--images mock` | 그림만 모의로 만듭니다. 기본은 `openai`(mock 엔진이면 `mock`) |
| `--openai-image-model`, `--openai-image-quality` | 그림 모델과 품질. 기본 `gpt-image-1.5`, `medium` |
| `--host 0.0.0.0` | 다른 컴퓨터에서도 접속하게 합니다(서버 배포용). 기본은 `127.0.0.1` |
| `--public` | 공개 서버 모드(위 「서버에 배포하기」 참고). `--daily-project-limit`, `--ip-daily-project-limit`, `--daily-image-limit`로 상한을 바꿉니다 |
| `--port 8766` | 다른 포트로 켭니다 |
| `--data-dir 경로` | 결과를 저장할 폴더. 기본은 이 폴더의 `data` |
| `--mock-fail 단계` | 모의 실행에서 그 단계를 처음 한 번만 실패시킵니다(`research`, `deep_research`, `storyboard`, `images`) |
| `--engine claude`, `--images agy` | 예전에 쓰던 Claude CLI 엔진과 Antigravity CLI 그림 작업자. 각각 로그인된 `claude`·`agy`가 필요하고, agy는 한도가 매우 작습니다 |

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `cardnews/server.py` | 웹 API, 공개 모드의 하루 상한 |
| `cardnews/worker.py` | 엔진·그림·렌더링을 웹 요청과 따로 실행하고 결과를 저장 |
| `cardnews/engines/` | 실행 엔진(`openai_api.py` 기본, `claude_cli.py`, `mock.py`). 프롬프트와 결과 형식은 `claude_cli.py`에 있고 OpenAI 엔진이 같이 씀 |
| `cardnews/images.py` | 그림 작업자(OpenAI, agy, 모의)와 그림 요청 문장 |
| `cardnews/render.py` | 카드 HTML → PNG, 잘림·겹침·대비 검사 |
| `cardnews/exports.py` | 내보내기와 내보낸 파일 검증 |
| `cardnews/procs.py` | claude·agy 프로세스 실행·취소·정리 |
| `cardnews/store.py` | SQLite 저장소 |
| `cardnews/static/` | 브라우저 화면 |
| `Dockerfile`, `docker-compose.yml`, `deploy/` | 서버 배포 |
| `data/` | 앱이 만든 결과. 저장소에 올리지 않습니다 |

## 막힐 때

| 증상 | 할 일 |
|---|---|
| "OpenAI API 키(환경 변수 OPENAI_API_KEY)가 없습니다" | 환경 변수(서버면 `.env`)에 키를 넣고 서버를 다시 켭니다 |
| "OpenAI API 키가 틀렸거나 만료됐습니다" / "크레딧이나 결제 한도가 부족합니다" | 키와 OpenAI 결제 설정을 확인합니다 |
| "OpenAI 안전 기준에 걸려 그림을 만들지 않았습니다" | 「글자 고치기」에서 그림 장면을 더 상징적으로 바꾸고 「그림 다시 만들기」를 누릅니다 |
| "오늘 … 모두 썼습니다" | 공개 모드의 하루 상한입니다. 내일 다시 하거나 상한 숫자를 바꿉니다 |
| 그림이 주제와 안 맞음(다른 나라 지도·국기·건물, 그림 속 글자 등) | 「글자 고치기」의 그림 장면에 장소와 상징을 분명히 적고(예: "센강과 에펠탑이 보이는 파리 지도", "글자를 쓰지 않는다") 「그림 다시 만들기」를 누릅니다 |
| 그림 단계에서 `Executable doesn't exist` 오류 | `uv run playwright install chromium`을 실행합니다 |
| `8765번 포트를 이미 다른 프로그램이 쓰고 있습니다` | 다른 서버를 끄거나 `--port 8766`으로 켜고 그 주소를 엽니다 |
| 서버를 다시 켰더니 「중단됨」이 보임 | 정상입니다. **다시 시도**를 누르면 저장된 선택·답변·기획과 이미 만든 카드는 두고 남은 작업만 다시 합니다 |
| 앱을 고친 뒤 예전 카드의 배치가 예전 그대로 | 카드 화면의 **모든 카드 다시 배치**를 누릅니다. 그림은 그대로 둡니다 |
| 카드에 "명암 대비 … 미만" 경고 | **글자 고치기**에서 상자 진하기를 올리거나 글자색을 바꿉니다 |
| 카드에 "글이 상자를 넘쳐 잘립니다" / "그림이 너무 작게 들어갑니다" 경고 | 본문을 줄이거나 글자 크기를 줄입니다 |
| 화면이 예전 모습 그대로 | 서버를 껐다 켠 뒤 새로고침(F5)합니다 |
